# Task 00 - Initialize the application skeleton

Create the initial command-line application structure for the Daily Habit Tracker.

## Requirements
- Provide a runnable CLI entry point.
- Add top-level commands for managing habits, logging completions, and viewing progress.
- Ensure the app prints helpful usage guidance for invalid or incomplete commands.

## Done when
- The CLI launches successfully.
- Command groups are visible and discoverable through help output.
