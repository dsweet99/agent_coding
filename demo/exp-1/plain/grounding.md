# Application: Daily Habit Tracker CLI

## Purpose
Create a small, practical command-line application that helps a single user track daily habits and maintain consistency over time.

## Objectives
- Let users define the habits they want to track.
- Let users record whether a habit was completed on a given day.
- Show clear progress feedback, including active streaks and recent completion history.
- Preserve user data between runs so tracking is continuous.
- Keep the experience simple and fast for everyday use.

## Constraints
- The application is for local, single-user use.
- It must work fully offline.
- It should prioritize clarity and reliability over advanced features.
- Data should remain consistent and recoverable after normal usage.
- Behavior should be predictable and easy to understand from command outputs.
